# CS-300-Final-Portfolio
This repository contains my final portfolio for CS-300: Analysis and Design. It includes work from Project One and Project Two, where I worked with different data structures and learned how they can be used for storing, searching, sorting, and retrieving information.

Project One

For Project One, I worked with and compared several data structures, including vectors, hash tables, linked lists, and binary search trees. I looked at how each one handled things like searching, inserting, removing, and sorting data. I also compared their run-time and memory use.

Project Two

For Project Two, I created a C++ program that loads course information from a file and stores the courses in a binary search tree. The program allows the user to load the course data, print the courses in alphanumeric order, and search for a specific course to display its title and prerequisites.

Reflection
What problem were you solving?

The main problem I was solving was how to store and organize course information so that it could be searched and displayed correctly. The program needed to read course information from a file, store the course number, title, and prerequisites, and allow the user to view that information. It also needed to print the courses in alphanumeric order.

How did you approach the problem?

I approached the problem by looking at the different data structures we worked with during the course and comparing how each one handled the tasks the program needed to perform. I worked with vectors, linked lists, hash tables, and binary search trees.

For the final program, I used a binary search tree because it worked well for keeping the courses organized by course number and made it possible to print them in order using an in-order traversal. I also split the program into different functions for loading the file, inserting courses, printing the list, and searching for a course.

Why are data structures important?

Data structures are important because the way data is stored can affect how easy and efficient it is to use. Some data structures are better for certain tasks than others. For example, hash tables can make searching by a key very fast, while a binary search tree can make it easier to keep information sorted.

Learning about Big-O notation also helped me understand that even if two programs do the same thing, one may work better than the other when there is a larger amount of data.

How did you overcome roadblocks?

One of the biggest challenges for me during this course was working with pointers and nodes. A small mistake could cause the program to crash or cause part of the data structure to stop working correctly.

I worked through problems by breaking the code into smaller sections and testing each part as I went. I tested things like loading data, searching, inserting, removing, and printing results to make sure everything was working the way it was supposed to.

I also had to pay attention to file validation in the final project so that invalid course information or prerequisites would not be loaded into the program.

How did this project change your software design approach?

This project helped me realize how important it is to think about the structure of a program before starting to code everything. Choosing the right data structure can make other parts of the program much easier.

I also became more comfortable breaking a larger problem into smaller functions. Before, I was more focused on just getting the program to work. Now I also think more about how the code is organized and whether it will be easy to change later.

How did it improve your ability to write maintainable, readable, and adaptable code?

This course helped me improve how I organize and explain my code. I used separate functions for different tasks instead of putting everything together in one section. I also added comments to explain what different parts of the code were doing and used names that made the code easier to follow.

I also learned that keeping code organized makes it easier to test, fix, and make changes later. This is something I plan to keep using in future programs.
